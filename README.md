# 🌴 Skyline Travel Club — WhatsApp Bot Architecture & Logic Tree

Презентация архитектуры, сценария и логики интерактивного WhatsApp-бота для турагентства **Skyline Travel Club**.

---

## 📌 Описание проекта

Проект представляет собой концепт и полный граф переходов чат-бота для обработки входящих заявок, подбора туров, записи на прием в офис и связи с оператором через WhatsApp.

### 🎯 Основные цели бота:
* **Автоматизация первичного контакта:** приветствие, выбор языка и сегментация клиентов.
* **Сбор лидов (Квиз/Форма):** опросы по направлению, составу группы и бюджету.
* **Запись на консультацию:** интеграция с календарем бронирования времени.
* **Перевод на менеджера:** бесшовный перевод диалога на оператора с паузой автоответов.
